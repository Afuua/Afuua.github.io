## 欢迎来到阿福的博客

这是第一篇测试文章。博客使用 [Astro](https://astro.build) 构建，部署在阿里云服务器上。

### 博客特性

- **极速加载** — 全站静态 HTML，零 JavaScript 运行时开销
- **Markdown 写作** — 内容即文件，用喜欢的编辑器写文章
- **标签系统** — 按主题分类，方便检索
- **RSS 订阅** — 第一时间获取更新
- **代码高亮** — 内置 Shiki 语法高亮

### 代码示例

```python
def hello():
    print("Hello, World!")
```

```ts
const greeting: string = "Hello, Astro!";
console.log(greeting);
```
