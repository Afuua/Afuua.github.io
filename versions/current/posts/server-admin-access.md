## 后台单独保护

后台路径可以通过 Nginx 反向代理到本地管理服务，再用 Basic Auth 或服务器防火墙限制访问。公开博客和后台管理最好分清入口。

## 配置重点

- 后台服务只监听服务器本机。
- Nginx 暴露一个不容易猜到的路径。
- 使用强密码，并只在需要时启动管理服务。
