## 一、Codex vs Cursor 对比

| 对比维度 | Codex | Cursor |
|---------|-------|--------|
| 开发方 | Anthropic | OpenAI |
| 默认模型 | Claude 模型 | 可自行替换任意模型 |
| 易用程度 | 产品设计更友好，适合零基础白领 | 自由度更高，偏向专业开发者 |
| 功能优势 | 浏览器操控、Computer Use、Image 2 生图、手机端操控 | Skill/MCP/斜杠命令/后运行操控 |
| 额度 | 20 刀很够用，额度大方 | 大多需自行调用 API，按量付费 |

**结论**：入门用 Codex 就很强，有条件两个都用。

---

## 二、核心能力一：本地文件操作

这是桌面端 AI 与对话式 AI 最显著的区别。

**项目（Project）**：选择本地文件夹后，Codex 可自由读写其中所有文件。权限有三种模式：默认权限、自动审查（推荐）、完全访问。同一项目可开多个对话，上下文独立。

**实战**：80+ 条视频素材按画面内容自动抽帧、拼缩略图、识别、重命名，全程自动。

---

## 三、核心能力二：命令行使用

Codex 在授权下可直接操作终端：安装依赖、下载软件、配置工具。

**实战案例**：安装 Node.js、Hermes、GitHub，安装 Skill 和飞书 CLI。可同时开多个对话并行执行不同任务。

---

## 四、核心能力三：持久记忆

- **全局 AGENT.md**：设置 → 个性化 → 自定义指令，每次对话都加载
- **项目级 AGENT.md**：仅当前项目生效，建议让 Codex 根据项目自动生成
- **自动记忆**：对话结束后自动总结，含来源、目标、关键词、偏好、踩坑记录

---

## 五、核心能力四：图片生成与网站开发

- **Image 2**：目前最强生图能力
- **网站开发**：打开计划模式 → 描述需求 → Codex 以选择题细化 → 确认执行
- **Defer**：长任务中随时补充指令，不打断运行
- **Fork**：从任意历史回复处开新对话分叉
- **批注**：选中页面元素写修改意见，自动带上批注发送

---

## 六、核心能力五：插件（Plugins）

插件 = Skill + MCP + CLI 的完整集合包。内置浏览器操作、屏幕操作、PPT/表格操作等。可从插件市场加装，如 Netlify 一键部署网站。

---

## 七、核心能力六：浏览器操控

Codex 可直接操控浏览器：点击、翻页、截图、填表。装 Chrome 插件后可操控已登录浏览器，后台多页面执行不占前台。

---

## 八、核心能力七：Computer Use（Mac 专有）

可操作电脑上所有 APP——打开音乐软件搜歌、操作微信等。功能强大但目前操作效率偏低。

---

## 九、核心能力八：Skill

Skill = 可复用方法、流程和工具的组合，AI 做特定任务的行动指南。推荐做法：先跑通流程，满意后让 Codex 沉淀成 Skill。

**实战**：热门项目推荐文章 Skill——装 GitHub 插件 → 问最新项目 → 挑 star 最多的写推荐 → 调整风格 → 配图 → 发飞书群 → 整套动作固化为 Skill。

---

## 十、核心能力九 & 十：MCP 与自动化定时任务

- **MCP**：发链接让 Codex 自己装，无需手动填参数
- **自动化**：结合所有能力，定点执行整套组合任务。如每周一早 9 点自动执行热门项目推荐 Skill、每天下午 6 点汇总未读邮件

---

## 核心心法：从"问 AI"走向"管理 AI"

用户的新角色：

1. 准备上下文和工作环境
2. 指派任务目标
3. 检查计划
4. 验收过程与结果
5. 把好方法沉淀为 Skill
6. 把重复任务设为自动化
