## 动画先确定空间

卡片出现效果如果只写透明度，会显得比较平。现在的目标是让卡片从页面深处浮出来，所以需要同时处理位移、缩放、透明度和 X 轴旋转。

## 关键参数

- 初始状态：向下偏移、缩小、透明、绕 X 轴后仰。
- 过渡状态：跟随滚动进入视口，逐渐抬起并放大。
- 最终状态：回到原位，正面朝向读者。

这些参数放在同一段动画里，视觉会更连贯。
