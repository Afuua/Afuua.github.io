## 快速搜索

项目里找文件和文本时，`rg` 真的很顺手。它快，而且默认会跳过很多不该搜索的目录。

```powershell
rg "TODO" src
rg --files
```

## 格式化

格式化工具的价值不只是统一风格，更重要的是减少讨论成本。

当团队里每个人都交给工具处理缩进、换行和引号时，代码评审就能更专注在逻辑上。

## 本地预览

做前端时一定要频繁打开真实页面看效果。只看代码很容易漏掉间距、对齐、移动端换行这些细节。

## 结语

效率工具不需要很多。真正留下来的，通常是那些每天都能少消耗一点注意力的东西。
