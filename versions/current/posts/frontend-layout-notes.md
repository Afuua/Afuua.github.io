## 为什么重新整理布局

一个博客首页不只是文章入口，也是在很短时间里告诉访客：这里写什么、更新频率如何、作者是什么样的人。

这次调整的目标很简单：让第一屏有记忆点，让内容区更容易扫描，让文章卡片在桌面和移动端都保持清晰。

## 信息层级

首页被拆成三个主要层级：

- 首屏 Hero 承担情绪和品牌识别
- 精选文章承担快速导读
- 卡片网格承担持续浏览

这样读者不需要一开始就面对一长串文本，也能很快知道该从哪里开始。

## 卡片密度

卡片里只保留标题、摘要、日期和标签。多余的内容会让列表变得吵，尤其是在移动端。

```css
.article-card {
  display: grid;
  overflow: hidden;
}
```

## 后续可以继续做

后面可以继续加入搜索、分页、分类过滤和文章封面字段。等文章数量上来之后，这些功能会更有价值。
